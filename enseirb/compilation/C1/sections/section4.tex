\section{Notion de passe de compilation}

Les phases de compilation ne sont pas à confondre avec les \notion{passes de compilation}. Une passe de compilation est un passage entier sur le code source qui peut effectuer plusieurs phases de compilation. Par exemple, une passe de compilation peut effectuer la phase d'analyse lexicale et la phase d'analyse syntaxique. Il faudra alors réaliser au moix deux passes de compilation pour effectuer toutes les phases de compilation.\\ \par
