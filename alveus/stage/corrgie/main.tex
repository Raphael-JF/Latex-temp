\section*{Exercice 2}

1) La borne longue du générateur est la borne \textbf{positive (+)}.  
La borne courte est la borne \textbf{négative (-)}.  

Le courant électrique circule du \textbf{+ vers le -} dans le circuit extérieur.

2) Les électrons circulent dans le sens inverse du courant, donc du \textbf{- vers le +}.

3) Dans la solution :
\begin{itemize}
\item Les ions potassium K$^{+}$ (positifs) se déplacent vers la \textbf{borne négative}.
\item Les ions permanganate MnO$_4^{-}$ (négatifs) se déplacent vers la \textbf{borne positive}.
\end{itemize}

\section*{Exercice 3}

1) Les fragments d’ADN sont des \textbf{molécules}, car l’ADN est une grande molécule constituée d’atomes liés entre eux.

2) Les fragments d’ADN sont \textbf{chargés négativement} car ils migrent vers la borne positive du générateur (les charges opposées s’attirent).

3) Le coupable est le suspect dont le profil (bandes) correspond exactement à celui trouvé sur la scène du crime.

\section*{Exercice 4}

1) La solution de sulfate de sodium étant incolore, la couleur verte est due à l’ion \textbf{fer(II)} : Fe$^{2+}$.

2) Le précipité vert montre la présence d’ions fer(II) : Fe$^{2+}$.

3) Le précipité de couleur rouille montre la présence d’ions fer(III) : Fe$^{3+}$.


4) Les ions fer(II) Fe$^{2+}$ se sont transformés en ions fer(III) Fe$^{3+}$ 
au contact du dioxygène de l’air.

5) Matériel nécessaire :
\begin{itemize}
\item bécher
\item éprouvette ou pipette
\item solution de soude
\item spatule
\item agitateur
\end{itemize}
